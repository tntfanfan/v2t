# 漫画制作资料

这里保留从已删除的旧前端目录提取的漫画坐标、气泡与角色校对记录，以及原有字体和许可证。文件内容迁移时逐一核对 SHA-256，没有改写历史记录。

- `data/`：S01E01、S03E10 制作数据、来源清单和角色修订记录。
- `fonts/`：原字体与许可证，用于后续漫画制作；实际产品中的气泡样式已包含在漫画素材里。

这些文件是内容制作资料，不是第三套网页。当前前端入口是 `frontend/web` 与 `frontend/miniprogram`。历史 JSON 中的旧路径记录当时的制作位置，可能已被清理；原始输入和正式分集成果仍位于仓库的 `input`、`output`。
